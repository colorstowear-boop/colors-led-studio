# Colors LED Studio

Programma per Windows di **Colors to Wear** per progettare scritte e insegne LED da stampare in 3D: scocca, faccia in PLA trasparente, scalino, fori, passaggio cavi, asole di aggancio, distanziali, divisione automatica dei pezzi grandi, dima di foratura ed esportazione 3MF/STL/SVG/DXF.

## Scaricare il programma
Vai su **Releases** (a destra in questa pagina), scarica `ColorsLEDStudio-Setup-x.x.x.exe` e installalo.
Quando esce una versione nuova, il programma la trova da solo e chiede se aggiornare.

## Pubblicare una nuova versione
1. Carica i file modificati (di solito `index.html`) con **Add file → Upload files**.
2. Vai su **Actions → Crea installer Windows → Run workflow** e scegli il tipo di versione.
3. Dopo circa 5–10 minuti la nuova versione è in **Releases** e tutti i PC la ricevono.
